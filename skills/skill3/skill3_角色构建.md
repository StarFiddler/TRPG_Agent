# 📦 Skill：character_builder_pipeline_v2

---

## 一、Skill 概述

**名称**：`character_builder_pipeline_v2`  
**类型**：流程型复合技能（Pipeline Skill）

---

## 二、输入（Input）

### 必选：
- 角色参考图（Image）
- 参考链接（Wiki / 设定页）

### 可选：
- 用户补充设定（关键词 / 风格 / 强化方向）

---

## 三、输出（Output）

统一输出一个完整 Markdown 文档，包含：

1. 角色卡（基础数值+设定）
2. 🎭 对话 System Prompt（人格层）
3. 🧠 战斗决策 AI（行为层）

---

## 四、核心能力

本 Skill = 三层结构：

### ① Character Layer（角色层）
- 外观
- 性格
- 背景
- 世界观适配

### ② Personality Layer（人格层）
- 对话风格
- 行为约束
- System Prompt

### ③ Behavior Layer（行为层）
- 战斗决策逻辑
- 状态机
- 技能策略

---

## 五、流程逻辑（升级版）

[Start]

1. 输入阶段
- 输入参考图 + 链接
- 可选关键词

↓

2. 解析阶段

2.1 视觉解析  
→ 外观 / 武器 / 风格  

2.2 文档解析  
→ 性格 / 背景 / 能力  

↓

3. 角色构建

→ 生成：
- 基础信息  
- 性格模型  
- 战斗定位  
- 属性  
- 装备  
- 技能  

↓

4. 人格生成（Prompt）

→ 生成：
- 身份定义  
- 性格约束  
- 行为规则  
- 语言风格  
- 禁止事项  

↓

5. 战斗AI构建

→ 构建：

5.1 状态机  
- SAFE / PRESSURE / PROTECT / EXECUTE  

5.2 行动优先级  

5.3 技能触发规则  

5.4 性格修正系统  

↓

6. 输出阶段

→ 输出 Markdown：

# 角色卡  
# 🎭 对话Prompt  
# 🧠 战斗AI  

[End]

---

## 六、设计原则

### 1. 人格与行为分离
- Prompt：控制说话  
- AI：控制行动  

### 2. 性格影响战斗
- 胆小 → 闪避权重↑  
- 守护型 → PROTECT↑  

### 3. 战斗AI可解释

输出必须包含：

【状态】  
【决策】  
【技能】  
【理由】  

### 4. 禁止纯随机
必须具备：
- 条件  
- 权重  
- 逻辑  

---

## 七、扩展接口

- skill4：战斗执行器  
- skill5：敌人AI  
- skill6：剧情系统  

---

## 八、总结

👉 本Skill = 角色 → AI化转换器  

输出角色具备：
- 可对话  
- 可战斗  
- 可成长
