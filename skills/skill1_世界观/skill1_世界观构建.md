# Skill：世界观与系统模块化生成流水线

## 概述

该 Skill 用于根据用户输入的关键词、文档或外部参考链接，先生成世界观，再按需生成等级系统、装备系统、技能系统、组队/宠物系统、交易系统，最后为所有系统输出对应数值用 prompt，并整理为多份 Markdown 文档。

---

## 输入

### 主输入
- 关键词
- 文档

### 外部输入
- 外部参考文档
- 外部参考链接

---

## 输出

- 世界观 Markdown 文档
- 等级系统 Markdown 文档
- 装备系统 Markdown 文档
- 技能系统 Markdown 文档
- 组队/宠物系统 Markdown 文档
- 交易系统 Markdown 文档
- 对所有系统的对应数值 prompt
- 多份对应 Markdown 文档集合

---

## 原始流程定义

```text
开始

1. 接收输入
   - 输入关键词/文档
   - 可接收外部参考文档/链接

2. 判断：是否给出参考链接文档？
   - YES：
       → read参考文档
       → creat世界观
   - NO：
       → ask世界背景
       → creat世界观

3. 判断：是否含有等级系统？
   - YES：
       → read参考文档
       → creat等级系统
   - NO：
       → 进入下一判断

4. 判断：是否含有装备系统？
   - YES：
       → read参考文档
       → creat装备系统
   - NO：
       → 进入下一判断

5. 判断：是否含有技能系统？
   - YES：
       → read参考文档
       → creat技能系统
   - NO：
       → 进入下一判断

6. 判断：是否含有组队/宠物系统？
   - YES：
       → read参考文档
       → creat组队/宠物系统
   - NO：
       → 进入下一判断

7. 判断：是否含有交易系统？
   - YES：
       → read参考文档
       → creat交易系统
       → 对所有系统输出对应数值的prompt
   - NO：
       → 对所有系统输出对应数值的prompt

8. 输出多份对应md文档
9. 生成MD文档

结束
