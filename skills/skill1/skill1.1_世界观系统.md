# skill：Worldview Engine v3（对抗优化版）

---

## 一、Skill定位（Definition）

该 Skill 是一个用于：

> 从【参考资料 / WIKI / 名称】构建“可运行世界模型”的生成系统

输出结果必须满足：

* 结构完整
* 逻辑自洽
* 可驱动剧情
* 可供其他LLM继续推演

---

## 二、输入参数（Input Schema）

### 必填

* `<世界名称>`

### 可选

* `<参考链接[]>`

* `<构建模式>`：

  * 还原型（严格复现原作）
  * 扩展型（补完缺失结构）
  * 原创型（仅保留风格特征）

* `<时间尺度>`：

  * 短期 / 中期 / 长期

---

## 三、核心原则（Hard Constraints）

1. **数据优先级**

   * WIKI / 官方设定 > 多源交叉验证 > LLM推断

2. **一致性原则**

   * 地理、文化、社会、时间线必须互相匹配
   * 禁止出现逻辑断层或设定冲突

3. **结构完整性**

   * 所有模块必须存在
   * 不允许缺失模块或弱化模块

4. **可执行性**

   * 输出必须可以直接用于：

     * 游戏系统
     * TRPG运行
     * 角色生成

---

## 四、Pipeline（核心流程）

---

### Step 1：World Data Acquisition

#### 有参考链接

* 解析全部 `<参考链接[]>`
* 提取：

  * 世界背景
  * 地理结构
  * 势力 / 阵营
  * 历史事件
  * 人物关系

#### 无参考链接

* 使用：

  * LLM知识
  * 联机检索（优先WIKI）

输出：

```
RawWorldData
```

---

### Step 2：Base World Modeling

构建五大基础模块：

```
BaseWorldModel = {
  地理设计,
  人文设计,
  风土人情,
  人际关系,
  社会关系
}
```

要求：

* 去冗余
* 统一命名
* 明确边界

---

### Step 3：Timeline System（时间线）

构建五阶段时间结构：

1. 起源阶段（神话 / 初始）
2. 发展阶段（文明形成）
3. 冲突阶段（战争 / 灾难）
4. 当前阶段（现状）
5. 未来趋势（预测）

要求：

* 必须形成**因果链**
* 每阶段必须可解释

输出：

```
WorldTimeline
```

---

### Step 4：Conflict Generator（冲突系统）

基于以下维度生成冲突：

* 资源
* 地理
* 信仰
* 权力
* 阶级

#### 冲突结构（强制模板）

```
Conflict {
  双方,
  根本原因,
  当前状态（潜伏/爆发/结束）,
  演化路径
}
```

要求：

* 冲突必须可扩展
* 至少包含 3 个核心冲突

输出：

```
ConflictMatrix
```

---

### Step 5：Player Entry System（玩家切入）

生成可执行入口：

#### 四类入口

1. 身份入口
2. 地理入口
3. 冲突入口
4. 任务入口

#### 模板

```
EntryPoint {
  身份,
  起始位置,
  初始目标,
  可发展路径
}
```

要求：

* 至少生成 3 个入口
* 必须可执行（非抽象）

输出：

```
PlayerEntryPoints
```

---

### Step 6：World Logic（世界运行逻辑）

必须定义：

* 世界驱动力
* 冲突生成机制
* 系统循环逻辑

要求：

* 世界必须“可持续运转”
* 不能是静态设定

---

### Step 7：Consistency Check

验证：

* 时间线 ←→ 世界结构一致
* 冲突 ←→ 社会结构一致
* 玩家入口 ←→ 当前世界状态一致

若冲突 → 自动修正

## 九、设计优势（用于对抗LLM）

* 强结构约束 → 防止跑偏
* 强模板限制 → 提高一致性
* 多层校验 → 降低幻觉
* 可递归扩展 → 适配复杂系统
* 可作为上游输入 → 驱动其他模型
