# 🎮 Skill4：跑团实例生成器（Game Runtime Builder）

## 一、Skill定位

**Skill4 = 系统整合层（Runtime Layer）**

用于： - 读取 01--08 系统模块 - 读取角色卡（多角色） -
构建完整跑团环境 - 生成可直接运行的 TRPG 游戏实例

------------------------------------------------------------------------

## 二、输入参数（Input）

### 1. 系统模块（必需）

-   md01：世界观系统\
-   md02：等级系统\
-   md03：装备系统\
-   md04：技能系统\
-   md05：组队系统\
-   md06：交易系统\
-   md07：数值规则\
-   md08：战斗系统

### 2. 角色卡（必需）

-   任意数量角色卡（前缀：角色卡\_）
-   每张包含：
    -   属性（Stats）
    -   技能（Skills）
    -   装备（Equipment）
    -   对话 Prompt
    -   战斗决策 AI

### 3. 跑团配置（用户输入）

``` yaml
GM: AI / 用户 / 协同
角色分配:
  角色名: AI / 用户
游戏风格: 硬核 / 叙事 / 轻量
难度: 简单 / 标准 / 困难 / 魂系
是否多角色操控: 是 / 否
```

------------------------------------------------------------------------

## 三、核心处理流程（Process）

### Step1：系统加载

构建系统对象： - WorldSystem - LevelSystem - EquipmentSystem -
SkillSystem - TeamSystem - EconomySystem - NumericSystem - CombatSystem

### Step2：角色实例化

每个角色转化为：

    CharacterInstance:
      - BaseStats
      - Skills
      - Equipment
      - AI_Behavior
      - DialoguePrompt

### Step3：控制映射

建立：

    GM -> 世界控制权
    玩家 -> 角色控制权

### Step4：规则注入

**判定规则**

    Roll(d100)
    成功率 = 属性 + 技能 + 修正 - 难度

**战斗规则** - 行动顺序：敏捷 - 行动类型：攻击 / 技能 / 道具 / 防御 /
位移 / 观察 - 状态：削韧 / 失衡 / 仇恨

### Step5：世界初始化

生成： - 起始场景（地点 / 环境 / 敌人 / 交互物） - 至少3种行动路径

### Step6：UI输出结构

必须包含： 1. 当前状态 2. 场景描述 3. 行动选项 4. 输入格式

### Step7：运行循环

    玩家输入 → 行动解析 → 判定 → 状态更新 → 世界反馈 → 下一回合

------------------------------------------------------------------------

## 四、输出结果（Output）

-   可运行跑团实例
-   完整规则已加载
-   玩家可直接开始游戏
