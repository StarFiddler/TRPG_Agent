# 📦 Skill：CombatSystemBuilderPipeline

## 一、Skill 概述

**名称**：`combat_system_builder_pipeline`  
**类型**：流程型复合技能（Pipeline Skill）

**输入**：
- 用户输入（关键词 / 文档 / 链接）
- 可选：参考资料（URL / 外部文档）

**输出**：
- 战斗系统 Markdown 文档（底层逻辑）
- 对应规则/数值 Prompt（可选扩展）

---

## 二、核心功能

该 Skill 用于：

> 从输入或参考资料出发，构建完整的战斗系统底层逻辑（回合制或即时制），并输出结构化 MD 文档

包含能力：
- 战斗模式判定（回合制 / 即时制）
- 战斗底层逻辑构建
- 规则抽象与文档化输出

---

## 三、流程逻辑（严格还原流程图）

```text
[Start]

1. 输入阶段
- 输入关键词 / 文档
- 可包含外部参考文档 / 链接

2. 判断：是否给出参考链接文档？
IF YES：
    → read参考文档
    → creat战斗底层逻辑
IF NO：
    → ask战斗基础设计（回合制 / 即时制？）
    → creat战斗底层逻辑

3. 输出阶段
→ 输出对应md文档
→ 生成MD文档

[End]
