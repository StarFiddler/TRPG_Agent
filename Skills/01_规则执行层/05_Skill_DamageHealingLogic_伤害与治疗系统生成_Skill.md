## 5. Skill_DamageHealingLogic：伤害与治疗系统生成 Skill

该 Skill 用于生成伤害、减伤、抗性、易伤、免疫、治疗、护盾、临时生命、濒死等逻辑。

### input

input 可以包括：

生命值规则；
伤害类型说明；
抗性说明；
护盾说明；
治疗规则；
死亡规则；
复活规则；
异常伤害规则；
环境伤害规则；
持续伤害文本。

### 处理目标

该 Skill 需要将不同作品中的“数值损益与生命状态变化”统一抽象为 DamageHealingLogic。

需要兼容的近似术语包括：

生命值；
HP；
血量；
体力；
耐久；
护盾；
临时生命；
伤害；
真实伤害；
物理伤害；
魔法伤害；
元素伤害；
精神伤害；
毒伤；
流血；
治疗；
恢复；
吸血；
减伤；
抗性；
易伤；
免疫；
濒死；
死亡；
复活。

### output

输出为该作品的 DamageHealingLogic，至少包括：

伤害来源；
伤害目标；
伤害类型；
基础伤害；
追加伤害；
伤害倍率；
抗性处理；
易伤处理；
免疫处理；
护盾处理；
临时生命处理；
减伤优先级；
治疗来源；
治疗上限；
治疗限制；
濒死或死亡条件；
复活或救援条件；
最终状态写回。

### logic 抽象格式

```yaml
DamageHealingLogic:
  source_input: 任意ACGN作品名称或wiki文档
  canonical_terms:
    - 生命值
    - HP
    - 伤害
    - 治疗
    - 护盾
    - 抗性
    - 易伤
    - 免疫
  source: 伤害或治疗来源
  target: 伤害或治疗目标
  base_amount: 基础数值、骰子、百分比、固定值或叙事等级
  damage_or_heal_type: 物理、魔法、元素、精神、毒素、环境、真实或其他作品专属类型
  modifier_order:
    - 免疫判断
    - 护盾或临时生命吸收
    - 抗性与易伤计算
    - 减伤与增伤计算
    - 最终生命变化
  healing_rule: 治疗、恢复、再生、吸血或复活规则
  down_rule: 倒地、濒死、失去战斗能力或死亡规则
  state_writeback: 写入生命值、护盾、伤势、死亡状态、复活状态或持续伤害状态
```

该 Skill 的作用是把不同作品中“数值如何改变生存状态”的机制转化为统一逻辑。
