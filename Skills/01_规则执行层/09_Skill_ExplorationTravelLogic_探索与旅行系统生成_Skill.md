## 9. Skill_ExplorationTravelLogic：探索与旅行系统生成 Skill

该 Skill 用于生成地图移动、地形消耗、侦查、潜行、追踪、迷路、天气、区域危险、随机遭遇等逻辑。

### input

input 可以包括：

地图资料；
地点说明；
旅行规则；
探索规则；
区域危险说明；
天气系统；
潜行规则；
追踪规则；
随机遭遇表；
世界尺度设定。

### 处理目标

该 Skill 需要将不同作品中的“非战斗空间行动”统一抽象为 ExplorationTravelLogic。

需要兼容的近似术语包括：

探索；
旅行；
移动；
地图移动；
区域移动；
潜行；
侦查；
调查；
搜索；
追踪；
迷路；
导航；
天气；
地形；
危险区域；
随机遭遇；
采集；
觅食；
攀爬；
游泳；
跳跃。

### output

输出为该作品的 ExplorationTravelLogic，至少包括：

地点节点；
区域节点；
移动单位；
移动速度；
地形影响；
天气影响；
光照影响；
导航判定；
侦查判定；
潜行判定；
追踪判定；
采集或觅食规则；
区域危险等级；
随机遭遇触发条件；
探索结果如何写回地图、任务和角色状态。

### logic 抽象格式

```yaml
ExplorationTravelLogic:
  source_input: 任意ACGN作品名称或wiki文档
  canonical_terms:
    - 探索
    - 旅行
    - 移动
    - 侦查
    - 潜行
    - 追踪
    - 随机遭遇
  map_unit: 区域、地点、房间、格子、节点、路线或叙事距离
  movement_rule: 固定速度、地形消耗、时间消耗、资源消耗或剧情移动
  environment_modifiers: 天气、光照、地形、噪音、障碍、危险等级或魔法环境
  exploration_checks: 侦查、调查、搜索、潜行、追踪、导航、采集或作品专属行为
  encounter_rule: 固定遭遇、随机遭遇、条件遭遇、巡逻遭遇或无遭遇
  discovery_rule: 发现地点、线索、资源、敌人、陷阱、捷径或隐藏事件
  state_writeback: 写入位置、时间、地图探索度、线索发现、资源消耗或遭遇触发
```

该 Skill 的作用是把不同作品中“角色如何在世界中移动和发现内容”的机制转化为统一逻辑。
