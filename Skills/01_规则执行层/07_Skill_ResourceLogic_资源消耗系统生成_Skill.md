## 7. Skill_ResourceLogic：资源消耗系统生成 Skill

该 Skill 用于生成生命、法力、体力、行动点、能量、弹药、材料、货币、冷却、次数、耐久等资源逻辑。

### input

input 可以包括：

角色资源说明；
技能消耗说明；
装备耐久说明；
物品消耗说明；
魔力、气力、怒气、灵力、精神力、弹药、材料等设定；
休息与恢复文本；
经济系统说明。

### 处理目标

该 Skill 需要将不同作品中的“可消耗或可恢复单位”统一抽象为 ResourceLogic。

需要兼容的近似术语包括：

生命；
HP；
魔力；
MP；
法力；
体力；
耐力；
精力；
气；
灵力；
咒力；
怒气；
能量；
行动点；
弹药；
材料；
金钱；
耐久；
冷却；
次数；
充能；
专注；
理智；
污染值。

### output

输出为该作品的 ResourceLogic，至少包括：

资源名称；
资源类型；
资源上限；
当前资源；
资源来源；
消耗条件；
恢复条件；
恢复速度；
资源不足时的处理；
资源是否可超上限；
资源是否会自然衰减；
资源是否会随等级或剧情成长；
资源是否绑定职业、装备、状态或地点；
资源变化是否写回角色状态或战役状态。

### logic 抽象格式

```yaml
ResourceLogic:
  source_input: 任意ACGN作品名称或wiki文档
  canonical_terms:
    - HP
    - MP
    - 体力
    - 能量
    - 行动点
    - 次数
    - 冷却
  resource_name: 资源名称或作品原术语
  normalized_resource_type: 生存资源、行动资源、能力资源、经济资源、物品资源、精神资源或剧情资源
  max_value: 最大值、等级成长值、固定值或无上限
  current_value: 当前值
  consume_rule: 消耗触发条件与消耗量
  recovery_rule: 恢复条件、恢复量与恢复周期
  insufficient_rule: 不足时禁止、降级、透支、反噬或转化为代价
  linked_systems: 能力、行动、状态、装备、休息、剧情或场景
  state_writeback: 写入当前资源、上限变化、冷却变化、次数变化或透支记录
```

该 Skill 的作用是把不同作品中“能力运行需要什么成本”的机制转化为统一逻辑。
