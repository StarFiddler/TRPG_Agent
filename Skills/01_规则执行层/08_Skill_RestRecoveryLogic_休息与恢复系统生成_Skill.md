## 8. Skill_RestRecoveryLogic：休息与恢复系统生成 Skill

该 Skill 用于生成休息、扎营、恢复、整备、安全区、存档点、治疗间隔、补给消耗等逻辑。

### input

input 可以包括：

休息规则；
安全区设定；
篝火、旅店、基地、据点、存档点等文本；
恢复说明；
野外扎营规则；
补给规则；
随机遭遇规则；
时间推进规则。

### 处理目标

该 Skill 需要将不同作品中的“脱离即时行动后的恢复与整备”统一抽象为 RestRecoveryLogic。

需要兼容的近似术语包括：

休息；
短休；
长休；
扎营；
整备；
恢复；
治疗；
据点；
安全区；
旅店；
篝火；
存档点；
检查点；
营地；
冥想；
疗养；
维修；
补给。

### output

输出为该作品的 RestRecoveryLogic，至少包括：

休息类型；
休息地点；
休息时长；
安全等级；
是否消耗补给；
可恢复资源；
不可恢复资源；
可解除状态；
不可解除状态；
是否推进时间；
是否触发随机遭遇；
是否刷新敌人、商店、任务或地图状态；
休息被打断的条件；
休息完成后的状态写回。

### logic 抽象格式

```yaml
RestRecoveryLogic:
  source_input: 任意ACGN作品名称或wiki文档
  canonical_terms:
    - 休息
    - 扎营
    - 整备
    - 安全区
    - 存档点
    - 篝火
  rest_type: 短休、长休、营地休息、安全区恢复、据点整备或作品专属恢复形式
  location_requirement: 安全地点、营地、旅店、据点、存档点、特殊设施或任意地点
  time_cost: 时间消耗、场景切换、回合消耗或无时间消耗
  recovery_targets: 生命、资源、状态、装备、冷却、次数、精神或剧情疲劳
  supply_cost: 食物、水、金钱、材料、耐久、药剂或无消耗
  danger_rule: 随机遭遇、敌人追击、休息打断或绝对安全
  world_refresh_rule: 敌人刷新、商店刷新、任务推进、时间推进或地图状态变化
  state_writeback: 写入资源恢复、状态解除、时间推进、地点状态或遭遇触发
```

该 Skill 的作用是把不同作品中“何时可以恢复、恢复什么、付出什么代价”的机制转化为统一逻辑。
